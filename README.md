# DMX AI

**Planning-only repository.** No product code yet.

AI lighting software for DJs and bands — a fusion of track-scripted DJ lighting (SoundSwitch), tactile live control (Wolfmix), and autonomous music-aware direction (MaestroDMX / Konductor).

**Status:** Research and planning complete. **Beachhead user not yet decided.**

Working product names floated during planning: **LumenForge**, **CueMind**, **StageBrain**. Repo name: **DMX AI**.
